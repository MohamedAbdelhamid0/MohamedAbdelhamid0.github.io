TryHackMe: Password Cracking Writeup

Hash Identification, Analysis, and Cracking Techniques

⚠️ Disclaimer: This write-up is for educational and security awareness purposes only. The techniques discussed are part of authorized penetration testing and security research training. Always practice responsible disclosure and ethical security research in controlled environments with proper authorization.

Question 1: Identify the Hash Type

Analysis

By checking the hash1.txt using hashid, we can easily determine that it's an MD5 algorithm. The hash contains only 32 characters, which narrows the possibilities down to either MD5 or NTLM. The context helps identify the correct algorithm:

  • If the hash was grabbed from a hacked web database: ~90% probability it's MD5
  • If the hash was grabbed from Active Directory: ~90-95% probability it's NTLM

In this case, the hash is identified as MD5.

Answer: md5

Question 2: Determine the Hash Mode for SHA-256

Analysis

By easily determining the word count in hash2.txt, we can see it's 64 characters long, which clearly indicates it's a SHA-256 hash. Now we need to find the corresponding mode number for hashcat.

We can either:

  • Search for the mode number in the hashcat documentation
  • Run the hashid command on hash2.txt to display the mode number

The hashcat mode number for SHA-256 is 1400.

Answer: 1400

Question 3: Crack the MD5 Hash Using Hashcat

Approach

We want to find the password of an MD5 hash we have (from hash1.txt). We know nothing about the password except that the hash is MD5. The best option to try right now is to run a dictionary attack using the rockyou.txt wordlist with hashcat.

This approach means hashcat will:

  • Hash each password in the rockyou.txt wordlist
  • Compare it to the hash we have (hash1.txt)
  • Report a match when found

Execution

hashcat -m 0 -a 0 hash1.txt /usr/share/wordlists/rockyou.txt

The command completed successfully and hashcat easily cracked the hash!

Answer: 123456

Question 4: Crack Multiple Hashes

Initial Analysis

By using the wc command to check the hashes initially, we observe:

  • hash2: 64 characters (SHA-256)
  • hash3: 32 characters (Likely MD5)

Since both hashes share the same password, we'll tackle the easier MD5 hash first to determine the password, then verify it works for the SHA-256 hash as well.

Cracking Strategy

We'll use the same hashcat approach with the rockyou.txt wordlist for the MD5 hash (hash3):

hashcat -m 0 -a 0 hash3.txt /usr/share/wordlists/rockyou.txt

Once we identify the password, we can verify it against both hashes to confirm they share the same plaintext password.

Key Takeaways

  • Hash Identification: Character count is the first indicator (32 chars = MD5, 64 chars = SHA-256)
  • Hashid Tool: Use hashid to quickly identify hash types and get hashcat mode numbers
  • Dictionary Attacks: Dictionary attacks with rockyou.txt are highly effective for common passwords
  • Hashcat Modes: Mode 0 is MD5, Mode 1400 is SHA-256, understand these mappings
  • Attack Types: Mode -a 0 represents dictionary/wordlist attacks in hashcat

Tools Used

  • hashid: Hash type identification utility
  • hashcat: Advanced password recovery tool
  • rockyou.txt: Comprehensive wordlist for password cracking
  • wc: Word/character count utility for determining hash length
