TryHackMe: Password Cracking Writeup

Hash Identification and Dictionary Attack Techniques

Introduction to Password Cracking

Password cracking is a critical cybersecurity skill that involves identifying passwords protected by various hashing algorithms. This writeup covers essential techniques for hash identification, determining the correct hashcat mode, and executing effective dictionary attacks using industry-standard tools and wordlists.

Question 1: Identify the Hash Algorithm

By checking the hash1.txt using hashid, we can easily see that it's an MD5 algorithm. Also, hash1.txt has only 32 characters, so it's either MD5 or NTLM. The only way to find out is to consider the context: if this hash was grabbed from a hacked web database, it's 90% MD5. However, if this hash was grabbed from Active Directory, then 90%-95% of the time it would be NTLM.

Answer: md5

Question 2: Determine the Hashcat Mode

By easily determining the word count in hash2, we can see it has 64 characters, which means it's SHA-256. Now we can either search and find the mode number, or we can run the identify command for hash2.txt, which will show us the mode number 1400.

Answer: 1400

Question 3: Crack the MD5 Hash Using Dictionary Attack

Now let's think about this scenario. We want to find the password of a hash we grabbed. This hash is MD5 (confirmed) and we know nothing about it. All we know is that it's MD5. The best option to try right now is to run the rockyou.txt command with hashcat. This basically means hashcat will hash each password in the rockyou wordlist and compare it to the hash we have (hash1.txt).

After running this command, hashcat easily cracked the hash!

Answer: 123456

Question 4: Crack Multiple Hashes

By using the wc command to initially check the hashes, we can see that hash2 has 64 characters (SHA-256) and hash3 has 32 characters, which is probably MD5. Let's try to crack the MD5 first since it's easier. Since both share the same password, let's take the easier step. We will use the same approach as we did in Question 3:

hashcat -m 0 -a 0 hash3.txt rockyou.txt

The command parameters are:

  • -m 0: Specifies MD5 hash mode
  • -a 0: Dictionary attack mode (straight mode)
  • hash3.txt: The file containing the hash to crack
  • rockyou.txt: The wordlist to use for the dictionary attack

Once we crack hash3 (MD5), we can now use the same password to verify against hash2 (SHA-256). Since both hashes were created from the same password, we can attempt to crack the SHA-256 hash using the mode 1400:

hashcat -m 1400 -a 0 hash2.txt rockyou.txt

Key Takeaways

Hash Identification Techniques

Understanding hash characteristics like character length is fundamental. MD5 produces 32-character hashes, while SHA-256 produces 64-character hashes. Tools like hashid automate this identification process.

Hashcat Modes

Each hashing algorithm has a specific mode number in hashcat. Mode 0 is MD5 (32 chars), and mode 1400 is SHA-256 (64 chars). Knowing these modes is essential for efficient password cracking.

Dictionary Attacks

Dictionary attacks are highly effective when using comprehensive wordlists like rockyou.txt. These attacks work by comparing hashed versions of dictionary words against the target hash.

Attack Mode Selection

Attack mode 0 (-a 0) represents a straight dictionary attack, which is the most common and effective for standard password cracking scenarios without additional rules or mangling.

Tools Used

Hashid

Identifies hash types based on character length and format. Essential for determining which cracking mode to use.

Hashcat

Industry-standard password cracking tool supporting multiple hash algorithms and attack modes with GPU acceleration.

Rockyou Wordlist

One of the most comprehensive and commonly used wordlists for dictionary attacks, containing millions of real-world passwords.

Linux Utilities (wc, etc.)

Command-line tools for analyzing file content and hash characteristics quickly without specialized tools.

Conclusion

Password cracking is a systematic process that begins with proper hash identification and ends with targeted attack strategies. By understanding hash characteristics, hashcat modes, and dictionary attack principles, security professionals can effectively assess password security and identify weak authentication mechanisms. Remember to always conduct these activities only on systems you have explicit authorization to test.
